# DecodeLabs Project 4 — The Serverless Logic

## Overview

A serverless computing project using AWS Lambda and Python to create a function that adds two numbers and returns the result in JSON format.

## Technologies

* AWS Lambda
* Python
* Amazon CloudWatch

## Example Input

```json
{
  "num1": 15,
  "num2": 25
}
```

## Expected Output

```json
{
  "Sum": 40
}
```

## Key Learning Outcomes

* Creating and deploying a Lambda function.
* Processing JSON input using Python.
* Testing serverless functions.
* Monitoring execution logs using CloudWatch.
